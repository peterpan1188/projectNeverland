# 📌 Phase 1 MVP Projects

## 🛡️ SpeakUp

### Anti-Bullying Reporting & Student Support App

A safe digital platform where students can report bullying incidents, communicate with school administrators, and access emotional support resources.

### Key Features

* Anonymous reporting
* Student & admin accounts
* Incident management
* Emergency support
* Real-time notifications
* Awareness campaigns

---

## 🐾 iKalinga

### Pet Adoption, Rescue & Animal Welfare Platform

An all-in-one animal welfare ecosystem connecting adopters, rescuers, shelters, volunteers, and concerned citizens.

### Key Features

* Pet adoption system
* Lost & found alerts
* Animal rescue requests
* Donation drives
* Abuse reporting
* AI breed detection
* AI age estimation
* Real-time rescue notifications

---

## 📍 AsanKana

### Location Tracking & Emergency Response App

A family-oriented safety application that allows users to instantly share live locations and emergency alerts with trusted contacts.

### Key Features

* Live GPS tracking
* One-click SOS
* Emergency notifications
* Trusted family groups
* Safe zone alerts
* Incident history

---

## 🏘️ Barangay Admin & Welfare System

### Community Governance & Resident Service Platform

A digital platform designed for barangay officials and residents to improve community services and administrative workflows.

### Admin Features

* Resident management
* Welfare monitoring
* Complaint handling
* Document processing
* Analytics dashboard

### Resident Features

* Online requests
* Welfare tracking
* Announcements
* Emergency assistance
* Appointment scheduling

---

## 🌴 Tourism Spot App

### Smart Tourism & Travel Companion Platform

An all-in-one tourism experience platform for destinations like Boracay and other travel hotspots.

### Key Features

* Hotel bookings
* Restaurant reservations
* Tour booking system
* Tourist maps
* WiFi/data purchases
* Emergency support
* Vehicle rentals
* Travel assistance
